# 提示音资源说明

`on.wav` / `off.wav` 来源于本机安装的 **Codex 桌面版**（MSIX 包）内置提示音：

- `on.wav`  ← `codex-notification.wav`（开启提示音）
- `off.wav` ← `codex-classic.wav`（关闭提示音）

放置位置（任选其一）：

1. `<游戏目录>\Mods\ZedZone.UltimateAssistant\sounds\`（推荐，模组更新不会覆盖）
2. `<游戏目录>\BepInEx\plugins\ZedZone.UltimateAssistant\sounds\`
3. 在 `BepInEx\config\zedzone.ultimateassistant.cfg` 的 `[Sound]` 段填写 `OnPath` / `OffPath` 绝对路径

仅用于个人本地备份与自用；版权归原应用所有，请勿再分发。
